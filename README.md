# Exercícios de TypeScript

Repositório com exercícios básicos de lógica de programação em TypeScript.

## Conteúdo

1. **Cálculo de multa por atraso** — calcula o valor total da multa com base nos dias de atraso e no valor da multa por dia.
2. **Classificação de atraso** — usa `if` para classificar o atraso em "Em dia", "Atraso leve" ou "Atraso alto".
3. **Categoria de livro (switch)** — usa `switch` para exibir a categoria de um livro de acordo com uma opção numérica.
4. **Múltiplos de 10** — percorre uma lista de números e indica quais são múltiplos de 10, sugerindo consultar a prateleira nesses casos.
5. **Maior, menor e média** — calcula o maior valor, o menor valor e a média de uma lista de números (páginas de livros).
6. **Empréstimos** — soma os valores de uma lista, calcula a média e conta quantos itens são maiores ou iguais a 15.

## Como rodar

É necessário ter o [Node.js](https://nodejs.org/) e o `ts-node` (ou o compilador `tsc`) instalados.

```bash
npm install -g ts-node typescript
ts-node nome-do-arquivo.ts
```

Ou, para compilar e rodar com Node:

```bash
tsc nome-do-arquivo.ts
node nome-do-arquivo.js
```
